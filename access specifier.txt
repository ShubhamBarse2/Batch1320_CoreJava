The final keyword in Java is used to restrict modification. Once something is declared as final, it cannot be changed, overridden, or inherited, depending on where it is applied. It is mainly used to provide security, consistency, and reliability in a program.

Where We Can Apply final Keyword
The final keyword can be applied to:

Variables
Methods
Classes


1. final Variable
Meaning:

A variable declared as final becomes a constant.
Its value cannot be changed once assigned.
Key Points:
Must be initialized once
Value cannot be modified
Used for fixed values
Commonly used with static → static final

  final double pi = 3.14;

2. final Method
Meaning:

A method declared as final cannot be overridden by child classes.

Key Points:
Used to prevent method overriding
Inheritance is allowed, but modification is not
Improves security and performance

3. final Class
Meaning:

A class declared as final cannot be inherited.
Key Points:
No child class allowed
Used when behavior should not be changed
Provides complete security


Interview Important Points :

final variable must be initialized once
final method prevents overriding
final class prevents inheritance
static final is used for constants
final improves security and clarity



 


Access Specifiers(Modifiers) : 


What is an Access Specifier?

Access Specifier in Java is used to control the visibility (accessibility) of classes, variables, methods, and constructors.



Types of Access Specifiers

Java has 4 access specifiers:

 public
 protected
 default
 private




1> public

Accessible from anywhere
Across class, package, project
Most open access level
Used for: API, library methods, model classes



2> private

Accessible only within the same class
Not visible to other classes
Supports encapsulation
Used for: data hiding (variables in OOPS)



3> protected

Accessible within:
same class
same package
subclass of other package (via inheritance)
Used for: inheritance-based programs


4> default 

If no specifier is written
Accessible only in same package
Also called package-private
Used for: package-level implementation

 




Important Rules : 

Class can be only public or default
Class cannot be private or protected
Members (variables/methods) can use all four
private supports encapsulation
protected supports inheritance





imp code reference : 

public class Demo {   //   Outer class    // public & default
	
	
	private class D  {     // Inner class // public , private , default , protected
		
	}

}
