Exception Handling in java : 

Exception --> Exception is an Unwanted Situation / Error which occurred during the execution of program
Exception Handling --> this is an process where we can handle type of Exception

Exception is also class in java which is present in java.lang package 

when the Exception is occurred in ur program then program will get stop also it provides information related to the Exception
which type of Exception , from where it Comes , why it comes 

there r 56 thousand + classes r present to handle Exception : 

there r two Types of Exceptions : 

1. Compile Time Exception(Checked Exception)
2. Run Time Exception(Unchecked Exception) 

note :  there is an Difference betn Error & Exception 



How we can handle the Exception : 

1. try , catch , finally block 
2. by using throw Keyword
3. by using throws Keyword 




try --> risky code (write code where Exception is occurred)
catch --> inside catch block mentioned which type of Exception is occurred(also write one msg to User)
finally --> it is always executable block( used for to close the Connection)




syntax : 




try {
 // Risky code 
} catch() {
 // MSG to User

}finally {
// always Executable block

}
